# Amarangamutima: Kinyarwanda emotion detection

Multi-label emotion detection (anger, disgust, fear, joy, sadness, surprise) for Kinyarwanda,
using AfroXLMR-base fine-tuned on the Kinyarwanda subset of BRIGHTER (SemEval-2025 Task 11).

Code, experiments and report: https://github.com/allia-wase/Kinyarwanda_Emotion.detection
